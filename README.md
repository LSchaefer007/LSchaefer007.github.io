# Logan Schaefer Engineering Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Files
- index.html
- styles.css
- script.js

## Run locally
Double-click `index.html`, or run:

    python -m http.server 8000

Then visit http://localhost:8000
