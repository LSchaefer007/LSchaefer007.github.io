RELIABILITY

Checking whether an action worked

PRIVACY

TESTING + DEBUGGING

Five failed tests pointed to old expectations, not broken authentication.

All 66 fast-gate tests passed, but five of 132 targeted tests failed. They expected HTTP 200 from protected routes; the hardened middleware correctly returned 403. I kept the stronger authentication and marked those tests for revision.
